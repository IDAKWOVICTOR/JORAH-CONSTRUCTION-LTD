# JORAH CONSTRUCTION LTD: Company Profile

Streamlit company-profile site.

    pip install -r requirements.txt
    streamlit run app.py

- Edit company facts (phone, email, website, services, portfolio text) at the top of `app.py`.
- Contact fields left empty are hidden. Enquiries from the form are saved to `enquiries.csv`.
- `build_assets.py` regenerates the optimised photos in `assets/` from the raw WhatsApp folders.
